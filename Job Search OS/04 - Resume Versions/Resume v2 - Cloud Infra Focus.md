# Resume v2 — Cloud Infra Focus

## What this version is for
General-purpose tailored version for Platform/Infra Engineer postings that
emphasize Terraform, Kubernetes, and CI/CD over on-call/incident work
specifically.

  Terraform-based infrastructure and Kubernetes."
